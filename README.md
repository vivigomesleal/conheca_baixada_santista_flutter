# Conheça a Baixada Santista

Aplicativo Flutter para o TP4 — Catálogo de Pontos Turísticos.

## Funcionalidades
- Lista de sete pontos turísticos em sete cidades da Baixada Santista.
- Nome, cidade, imagem ilustrativa e descrição.
- Checkboxes para marcar cada lugar como favorito e/ou visitado.
- Contadores de favoritos e visitados atualizados com `setState`.
- Dados mantidos somente em memória; ao reiniciar o app, as marcações voltam ao padrão.

## Pontos incluídos
1. Cachoeira do Paraíso — Peruíbe
2. Cama do Anchieta — Itanhaém
3. Poço das Antas — Mongaguá
4. Fortaleza de Itaipu — Praia Grande
5. Teleférico e Morro da Asa Delta — São Vicente
6. Jardim da Orla - Santos
7. Mirante das Galhetas - Guarujá
8. Forte São João — Bertioga
